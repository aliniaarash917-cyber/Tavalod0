# 🎂 تولدت مبارک، نسا

یک سایت تک‌صفحه‌ای برای تولد، ساخته‌شده با HTML، CSS و JavaScript خالص — بدون هیچ فریم‌ورک، بدون هیچ فایل رسانه‌ای دانلودی.

## ✨ چی توش هست

| بخش | توضیح |
|---|---|
| **هیرو** | نام با گرادیان متحرک و افکت متن |
| **نامه** | متن عاشقانه با افکت تایپ‌رایتر |
| **موزیک** | آهنگ ۳۲ ثانیه‌ای که با Web Audio API **همین‌جا** ساخته می‌شه + زیرنویس سینک‌شده + ویژوالایزر |
| **بازی** | «قلب‌ها رو بگیر» — ۱۵ قلب در ۴۵ ثانیه، با رکورد محلی |
| **کیک** | سه شمع که با کلیک فوت می‌شن |
| **شیشه‌ی آرزو** | ۱۰ جمله‌ی نگفته که یکی‌یکی بیرون می‌آن |
| **پایان** | کاغذرنگی (confetti) و امضا |

## 📁 ساختار

```
.
├── index.html
├── css/
│   └── style.css
└── js/
    ├── audio.js   ← ساخت آهنگ، زیرنویس، ویژوالایزر
    ├── game.js    ← منطق بازی قلب‌ها
    └── main.js    ← ذرات، تایپ‌رایتر، کیک، شیشه، confetti
```

## 🚀 اجرا

فقط `index.html` رو باز کن. همین.

برای سرور محلی:

```bash
python3 -m http.server 8000
```

بعد برو به `http://localhost:8000`

## 🎵 درباره‌ی موزیک

هیچ فایل mp3 یا wav ای وجود نداره. ملودی، پدها و بیس به‌صورت آرایه‌ی نُت داخل `js/audio.js` تعریف شدن و با `OscillatorNode` و `ConvolverNode` (ریورب) به صدا تبدیل می‌شن.

برای تغییر آهنگ، آرایه‌های `MELODY`، `PADS`، `BASS` و `SUBS` (زیرنویس‌ها) رو ویرایش کن.

> ⚠️ مرورگرها اجازه‌ی پخش خودکار صدا نمی‌دن. آهنگ فقط بعد از کلیک روی دکمه‌ی ▶ شروع می‌شه.
